# Changelog

All notable changes to `laravel-aba-payway` will be documented in this file.

## [1.0.0] - 2024-10-13

### Added
- Initial release of Laravel ABA PayWay package
- Complete integration with ABA PayWay payment gateway
- Secure hash-based authentication
- Transaction management with Eloquent model
- Automatic callback/webhook handling
- Customizable payment forms
- Comprehensive test coverage
- Support for multiple currencies (USD, KHR)
- Production and sandbox environment support
- Database migration for transaction storage
- Service provider for automatic registration
- Facade for easy usage
- Configuration file with environment variables
- Built-in controllers for handling payments and callbacks
- Routes for payment processing and status checking
- Exception handling for payment errors
- Comprehensive documentation and examples

### Features
- Payment creation and processing
- Transaction status tracking
- Callback verification and processing
- Multi-currency support
- Sandbox and production environment support
- Comprehensive logging
- Laravel 10.x, 11.x, and 12.x support
- PHP 8.1+ compatibility
